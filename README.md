# School SIS

A High School Student Information System starter built with:

- Next.js
- TypeScript
- Prisma
- PostgreSQL
- Tailwind CSS

## Features

- Staff authentication
- Role-based access
- Principal, Admin, Teacher, Accountant/Bursar, Registrar, Counselor roles
- Registration periods
- New student registration
- Photo upload
- Previous academic record upload
- Student list and student profile
- Annual grade promotion API
- Age calculation from date of birth
